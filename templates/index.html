Under the hood

Every prediction is a probability, not a fact.

Each model doesn't "know" the next word — it scores every word in its vocabulary and the highest-scoring one gets chosen. Click a token above and its runner-up candidates stay visible in the lane, so you can see how confident — or unsure — each architecture was.

01

Tokenize

Your sentence is mapped to integer IDs using the same word index the models were trained on. Unseen words become <OOV>.

02

Pad to window

The sequence is left-padded to {{ max_sequence_len - 1 }} tokens, matching the fixed-length input both networks expect.

03

Score the vocabulary

A softmax over {{ vocab_size }} words gives a probability to every possible next word — shown as the bars beneath each token.

04

Append & repeat

The top word is appended to the sentence and fed back in, so the model generates its own continuation one word at a time.

Architecture

Same data, same recipe, one difference.

Both models share an embedding layer, dropout, and dense head. The only swap is the recurrent cell — LSTM's gated memory versus SimpleRNN's plain feedback loop — which is exactly why their predictions start to diverge on longer sentences.

LSTM SimpleRNN
Recurrent cell Bidirectional LSTM(100) → LSTM(100) Bidirectional SimpleRNN(100) → SimpleRNN(100)
Embedding dim 64 64
Memory mechanism Input / forget / output gates Single tanh feedback loop
Typical strength Holds context over longer spans Faster, lighter, forgets sooner
Dense head Dense(100, relu) → Dense(vocab, softmax) Dense(100, relu) → Dense(vocab, softmax)
